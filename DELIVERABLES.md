# Final Deliverables

The completed repository should contain enough evidence to present the project in an interview.

## Required

- architecture diagram;
- application source;
- Dockerfile;
- Terraform;
- Helm chart;
- GitOps configuration;
- GitHub Actions workflows;
- validation evidence;
- troubleshooting notes for several scenarios;
- monitoring dashboard screenshot/export;
- short cost discussion;
- README explaining deployment and cleanup.

## Final demonstration

Be prepared to perform a short demo:

1. show the architecture;
2. make a small application change;
3. open/merge the change;
4. show CI;
5. show the SHA image in ECR;
6. show the desired-state update;
7. show Argo CD reconciliation;
8. show the new pods;
9. call the application through HTTPS;
10. show metrics;
11. explain rollback;
12. explain one troubleshooting incident.

## Resume bullet exercise

Write 2–3 bullets describing what was built and measurable outcomes demonstrated by the project.

Do not invent production business impact. Describe what the lab actually proves.
